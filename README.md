# Distributed File Storage System

A self-guided C++ project implementing a distributed file storage system using TCP socket programming.

## Project Details

* **Self-Guided Project**
* **Language/Libraries**: C++ (with Winsock2/POSIX cross-platform socket wrapper)

## Core Features

* **Distributed File Storage**: Built a distributed file storage system in C++ using TCP socket programming, enabling file chunking, multi-node storage, and reliable data retrieval.
* **Master-Server Architecture**: Designed a master-server architecture to manage chunk distribution and metadata mapping across storage nodes.
* **Replication & Fault Tolerance**: Implemented replication and fault tolerance, ensuring high availability and resilience against node failures.
* **Custom TCP Protocol**: Developed a custom TCP-based communication protocol to handle file upload, download.
